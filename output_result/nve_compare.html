NVE 保存量のまとめ — dt = 2.0 〜 0.2 fs（8 本）

純 KNbO₃ 2,560 原子．150 K・0 GPa で平衡化した NPT の step_39000.xyz から，速度とシェル変位を引き継いで開始．cgtol = 1e-6，shell_extrap_order = 2．4 ps まで比較．統計値は最初の 0.5 ps を除く．ΔH′ = (K + U)(t) − (K + U)(0)．W_d = Σ F̄_res·Δs（シェル残差がした仕事）は 23 列 log の 3 本（0.75 / 1.5 / 2.0 fs）だけ．作成 2026-11-20 00:44．

分かったこと

  • ドリフトはシェル残差がした仕事 W_d で完全に説明できる．W_d を足した保存量 ΔH′ + W_d は，0.75 fs で +6.82 → −0.00，1.5 fs で +4.99 → −0.02，2.0 fs で +3.65 → −0.23 μeV/atom/ps（2.0 fs で少し残るのは W_d を台形則で見積もる誤差が dt とともに増えるためと考えられる）．時間積分（コア側）にはドリフトの原因がない．
  • cos θ の平均は負（−0.24 〜 −0.41）．残差はシェルの動きと逆向きに偏っている．予測子（2 次外挿）がシェルを極小より先へ行き過ぎた位置に置き，CG が戻しきれなかった分が「戻る向き」の力として残る，と解釈できる．F̄·Δs < 0 なので U が増える方向，つまり保存量が上がる向きのドリフトになる．
  • ドリフトは dt ≈ 0.4〜1.0 fs で最大（+5.5〜+6.8），0.4 fs 未満で急に小さくなる（0.3 fs で +2.9，0.2 fs で +0.7）．1.0 fs より大きい dt ではむしろゆるやかに下がる（1.5 fs で +5.0，2.0 fs で +3.7）．
  • どの dt でもドリフトは一定の速さ．1 ps ごとの傾きがほぼ同じ．毎ステップ同じ割合で積み重なる系統的な効果．
  • ゆらぎ（積分誤差）は dt² にほぼ比例．2.0 fs でも系は壊れていない（温度も一定）．
  • 小さい dt でドリフトが消える仕組みは未検証．cos θ を記録しているのは 0.75 fs 以上の 3 本だけ．0.2・0.3 fs を 23 列のコードで回し直せば，cos θ が 0 に近づくのか，残差の大きさ側が変わるのかを分けられる．
  • 実用上：W_d を足した ΔH′ + W_d を見れば，dt やシェル収束の影響と，積分そのものの精度を切り分けて評価できる．ドリフトそのものを消すには，dt を下げるより予測子（外挿次数・ASPC・XL-BOMD）を変える方が安い．
